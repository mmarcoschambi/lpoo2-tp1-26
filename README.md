# LPOO II 2026 - TP1 / TP2

**Carrera:** Analista Programador Universitario (APU) - Facultad de Ingeniería (UNJu)  
**Materia:** Laboratorio de Programación Orientada a Objetos II  
**Grupo:** 13

## Abrir y ejecutar

La solución válida del repositorio es:

`LPOOII_GRUPO13/LPOOII_GRUPO13.sln`

Contiene dos proyectos:

- `Vistas`: aplicación WPF ejecutable.
- `ClasesBase`: biblioteca de clases del dominio.

Después de clonar, abrir la solución en Visual Studio. Si Visual Studio no conserva un proyecto de inicio, hacer clic derecho sobre **Vistas** y seleccionar **Establecer como proyecto de inicio**. Esta selección puede guardarse como configuración local del usuario en versiones antiguas de Visual Studio.

## Estado funcional

La aplicación inicia en el Login, valida los roles Admin/Vendedor y abre el menú principal. Los formularios de alta implementan el flujo requerido de Nuevo, Guardar, Cancelar y Salir. Los recursos visuales del TP2 se encuentran dentro de `LPOOII_GRUPO13/Vistas`.
